# Aurora Studio distribution license summary

Aurora Studio's product license is GPL-3.0-only; see the installed `LICENSE`.
The first-party files enumerated in `APACHE-FILES.txt` retain Apache-2.0; see
the installed `LICENSE-APACHE`. Both complete license texts are included in
the package.

Third-party projects keep their own Apache-2.0, MIT, BSD-2-Clause,
BSD-2-Clause-FreeBSD, BSD-3-Clause, BSD-4-Clause, and GPL-2.0-only with
Classpath exception terms. The package installs the matching source notices
and JNI `ASSEMBLY_EXCEPTION` under `share/doc/aurora-studio/third-party/`
without changing their contents.

Source origins and the exact Apache-2.0 file set are documented in
`PROVENANCE.md` and `APACHE-FILES.txt`.
